## 📖 Descripción
Este proyecto analiza el impacto y la distribución de la tuberculosis en México utilizando bases de datos oficiales del **INEGI**. El análisis se centra en la limpieza de datos masivos, visualización de tendencias y detección de focos rojos a nivel estatal/municipal.
